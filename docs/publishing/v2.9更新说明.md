# v2.9 发布说明

v2.9 把开局工具从集中初始化进一步拆成研究、政治、外交、装备与建设五组独立操作，并修复 v2.9 测试线实机反馈的问题。

主要变化包括按年份研究、稳定度与战争支持、自治度与顺从度、国际关系、意识形态与国体、法案、战争借口及特殊规则；预设设计与库存顺序门槛；全国军工厂、电网、要塞群和大型设施；建设加速 +5000%；潜艇 MIO 与 +1000 好感。

《Götterdämmerung》环境下，大型设施优先建民用核反应堆；之后完成核能特殊科研不会再额外补建普通核反应堆。最终实机点验为民用核反应堆 1、普通核反应堆 0，日志未发现 MOD 脚本或文本错误。

开发侧新增固定版本、固定哈希的 CWTools 本地语义检查，减少仅靠 AI 审查脚本的依赖。
