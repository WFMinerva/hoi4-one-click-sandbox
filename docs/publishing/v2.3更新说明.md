# v2.3 发布说明

## 主要更新

- 军工机构初始化扩展到所有玩家国家：只处理当前国家实际拥有的MIO，自动完成合法特质路线，不额外增加资金或等级。
- 同一局游戏切换国家后，“开局一键爽玩”分类仍会显示；一次性初始化、改编、进化编制与特殊科研均按国家分别记录。
- 特殊科研后二阶段进化编制开放给所有非AI玩家国家。
- 基础装甲师改为12机械化＋6中型自行火炮；主力步坦师及其进化型中的轻型自行火炮纠正为中型自行火炮。
- 前置条件不足的决议保持可见并明确提示；更新通用与PRC初始化完成事件文案。

## 兼容性

适配 Hearts of Iron IV 1.19.*。按全DLC环境制作；特殊科研功能需要《Gotterdammerung》。AI不会执行本MOD决议。
