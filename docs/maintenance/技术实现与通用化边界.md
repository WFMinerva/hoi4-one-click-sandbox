# 技术实现与通用化边界

## 一、总体架构

v2.0采用“通用核心＋PRC增强层”。脚本文件仍沿用`PRC_OCS_`前缀，这是稳定键名，不代表功能仍仅限PRC。不得为了美观批量重命名这些键，否则可能破坏存档标志、事件和本地化引用。

## 二、国家识别

通用入口面向所有`is_ai = no`国家。PRC增强层使用`tag = PRC`与`original_tag = PRC`识别，确保PRC改国号或形成动态身份后仍保留专属效果，同时避免其他中国国家误获PRC内容。

## 三、科技

科技效果继续使用明确列出的原版科技键，实机效果按用户判断等同控制台`research all`。主要国家科技树外观可能不同，但不另做逐国科技分支。

## 四、装备和模板

- PRC与非PRC分别创建中国名称和中性名称的22个设计。
- 通用设计不得引用PRC专属`design_team`。
- PRC的“主力纯步师”“卫戍部队”“主力步坦师”保留民兵营。
- 非PRC三个对应模板将民兵营全部替换为普通步兵营，共42处。
- 初始化只创建模板，不自动改编现役部队。
- 独立改编决议将全军改成同名“卫戍部队”，模板会按国家分支解析。

## 五、24师增援

一次性决议仅在初始化后显示，选择本国拥有且控制的一个州，连续执行24次`create_unit`，使用同名“主力纯步师”。每个师设置100%人力、装备和初始训练度。执行后设置国家标志并隐藏，避免重复领取。

## 六、建设作用域

所有通用建设使用`every_owned_state`并在单一`limit`块内检查`is_controlled_by = ROOT`。沿海船坞同时在同一个`limit`块中检查`is_coastal = yes`。禁止重新写成两个并列`limit`，否则会触发：

`Multiple limits in target effect`

## 七、电网与补给站

- PRC保留双电网与23座固定补给站。
- 其他国家完全跳过电网效果。
- 固定补给站依赖中国州和省份ID，不能通用。
- 通用铁路自动化已经放弃，不得复活v1.1a/v1.1b路线。

## 八、已知历史现象

PRC双电网曾观察到大庆、阿萨姆和新疆部分地区出现原版油田勘探项目。原因未确认，v2.0没有扩大到其他国家。后续若研究，应使用前后存档州块差分，不得凭猜测修改建筑或资源脚本。
