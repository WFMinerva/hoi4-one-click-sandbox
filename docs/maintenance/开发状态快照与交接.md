## 5. 踩坑经验（通用条款，跨工具链）

1. **`Expand-Archive` 解压嵌套**：将 ZIP 解压到已存在的同名目录会得到 `根/子目录/内容` 的双层嵌套；启动器按 `.mod` 的 `path` 找 `descriptor.mod` 时会扑空 → MOD 未加载、无决议。正确做法：先删除旧目录，再解压到 `mod` 根目录，并立即用目录列表核对 `descriptor.mod` 层级。
2. **`.mod` 文件 `path`**：仓库约定 `path="mod/OCS_one_click_sandbox_start_v2_0"`，内容目录必须与该相对路径匹配（`mod/OCS_one_click_sandbox_start_v2_0/descriptor.mod`）。启动器层面 `dlc_load.json` 会记录启用状态。
3. **启动器缓存**：`Documents\Paradox Interactive\Hearts of Iron IV\` 下的 `dlc_load.json` / `launcher-v2.sqlite` 记录 MOD 启用与注册；反复删除/重建 MOD 目录后若启动器不识别，可清理相关缓存后重开启动器。
4. **日志读取注意事项**：
   - 编辑器占用日志文件通常不影响读取（共享读锁），但游戏启动时若文件被独占占用可能写不进去，进游戏前建议关闭日志查看窗口。
   - `read_file` / `search_files` 可能返回**缓存旧内容**；判断"最新一轮"要看日志文件时间戳，而不是依赖对话中的历史读取结果。
   - `error.log` 顶部 6 行 `gamelobby.cpp` / `remotefile.cpp` 的 `Failed allocate data buffer` 是游戏本体网络模块噪音，**与本 MOD 无关**，无 MOD 时也会出现。
5. **PowerShell 转义**：默认终端为 PowerShell；`&&` 不是有效语句分隔符（用 `;`），`grep` 命令不存在（用 `findstr`），`$_` 在命令行粘贴时会丢字符，复杂命令建议写成独立的 `.ps1` 或避免内联 `$_`。
