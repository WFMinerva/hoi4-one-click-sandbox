# 开局一键爽玩 v2.0 完整技术交接资料包

## 当前唯一正式基准

- 正式版本：v2.0
- 直接来源：用户实机验证无误并明确认定稳定的 v2.0c2
- 正式化处理：只清理测试标识、更新版本号和安装目录名称，不改变任何游戏逻辑
- 游戏环境：Hearts of Iron IV 1.19.*，全DLC，单人游戏
- AI：所有本MOD决议均不可执行

## 首先使用的文件

1. `01_当前稳定版/开局一键爽玩_v2.0_正式版.zip`：当前唯一发布与后续修改基准。
2. `02_完整源码/v2.0_source_tree/`：与正式包一致的完整源码。
3. `00_从这里开始/功能与版本交接单.md`：功能边界、版本状态和后续工作规则。
4. `00_从这里开始/技术实现与通用化边界.md`：通用核心与PRC增强层的实现说明。
5. `00_从这里开始/测试状态与回归清单.md`：已经验证的内容和仍建议补做的多国家回归。

## 版本规则

- v2.0为当前稳定基准，后续不得退回v2.0c、v2.0b或v1.2c继续开发。
- v2.0c存在重复`limit`语法错误，已被v2.0c1修复，禁止复用。
- v1.2c仅作为PRC专用稳定历史基准与技术参考，不能覆盖v2.0通用正式线。
- 新功能必须从v2.0完整复制后修改，使用新的测试版本号，并经实机验证后才能替换稳定版。
