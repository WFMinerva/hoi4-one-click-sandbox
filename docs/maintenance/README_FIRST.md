## 维护纪律

- v2.6为当前稳定基准，后续不得退回旧版本继续开发。
- `PRC_OCS_`前缀是稳定键名，不做批量重命名。
- 通用玩家决议必须保留AI守卫；PRC增强层同时覆盖 `tag = PRC` 与 `original_tag = PRC`。
- 建设只处理当前国家拥有且控制的州；同一作用域不得出现多个 `limit`。
- 不修改原版国策、国家历史与事件链。
- `dist/`只由 `tools/build_release.py`生成。
