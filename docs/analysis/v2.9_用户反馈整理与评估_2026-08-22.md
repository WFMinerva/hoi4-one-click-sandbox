## 一、缺陷类（已对照源码核实）

### B7. 纯沿海国家「扩建全国民用工业体系」按钮不亮

- 现状（两处已核实）：
  1. `common/decisions/PRC_OCS_decisions.txt` `PRC_OCS_queue_civilian_industry` 的 `available`：`any_owned_state` 需同时满足石化完成（`refinery_target_complete`＋`fuel_silo_target_complete`）且 `OR = { NOT = { is_coastal = yes } has_state_flag = PRC_OCS_coastal_dockyards_queued }`——**所有州均为沿海的国家（英/日等）必须先把船厂点到目标（dockyard > 19 才置 flag）**，否则按钮恒灰。
  2. `common/scripted_effects/PRC_OCS_construction_effects.txt` `PRC_OCS_queue_civilian_industry_effect` 内同名条件确认同链（Priority 4 注释：沿海州民用须等船厂目标完成）。
- 根因：这是「石化→船厂→民用」优先级链的**设计前置**，非崩溃级 bug，但对纯沿海国家表现为「按钮莫名不亮」，无任何提示说明前置。
- 修复方向（低风险，二选一或并用）：① 放宽民用决议 `available`/效果条件——沿海州民用不再依赖船厂 flag（与船厂互相独立），或 ② 保留链但在 tooltip 键 `PRC_OCS_queue_civilian_industry_available_tt` 写明「沿海州需先完成全国船厂目标」；建议顺带把石化/船厂同样缺提示的前置都补一句 tooltip。
- 影响面：仅条件与本地化文案，不破坏存档。
