## 本轮修复（继承 v2.7 正式基准与 v2.8-test1 的 B1/B2/B3，变更记录 #3）

- **N1 巡洋潜艇 MtG 模块分支补齐**：特殊科研「选择原型奖励」海军菜单的巡洋潜艇（事件 19）原先只复刻了无《Man the Guns》时的装备加成分支；本轮补上 MtG 分支——有 MtG 时选项解锁潜艇模块（「灵活运用」=附加油箱模块 /「武装」=潜艇轻型炮模块），无 MtG 时仍为原航程/鱼雷加成。选项悬浮提示（`_tt`）已同步说明两种分支。
- **L1 陆军菜单补齐陆地巡洋舰与超重型榴弹炮选项**：v2.6 分析工具曾因 `equipment_bonus` 属项目作用域而整体排除陆地巡洋舰 8 组（底盘/发动机/炮塔/履带/通信/装配/悬挂/弹药）与超重型榴弹炮、自行超重型榴弹炮各 1 组三选一。本轮将其具名移植为 `add_equipment_bonus`，全部并入陆军菜单 48。
- **海军同类遗漏 4 组**：核鱼雷、AIP 发动机、消声瓦、近炸引信的原型互斥选择并入海军菜单 51。
- **新建火箭菜单 52**：飞行炸弹设计（均衡/航程/载荷）与弹道导弹制导（机械制导/无线电制导）两组互斥奖励并入新建的火箭菜单 52，配套新增「选择火箭特殊科研原型奖励」决议。
- 事件 ID 空间：新组使用 54–69，火箭菜单使用 52（53 为骷髅师事件，不受影响）。
