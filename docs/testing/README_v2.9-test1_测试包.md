## 本轮变更（继承 v2.8 正式基准，变更记录 #8 批次 1：B7＋T1＋T2）

- **B7 沿海国家民用工业按钮修复**：纯沿海国家（英/日等）此前必须先完成「扩建全国沿海造船工业」目标，「扩建全国民用工业体系」按钮才会亮起（且无任何提示）。现移除该前置——只要完成石化目标即可点击民用工业，决议说明与 tooltip 同步更新。
- **T1 预设学说改版**：「启动一键爽玩开局」预设学说由「人海突击＋人民民兵/游击战」体系改为「决战计划＋优势火力」体系——陆军总学说新增决战计划与优势火力（撤人海突击）；步兵分支预设「卓越单兵」（commandos）、作战分支预设「渗透战术」（infiltration tactics）；空军分支改「战斗轰炸机／空中火炮／重型飞行器重心」；预设军种精神联动换为优势火力与决战计划系（撤大规模突击学院与就地取食）。
- **T2 共享 MIO 路线修正**：`tools/generate_universal_mio_effect.py` 按组织类型（原版 include 模板）应用偏好——
  - 支援装备制造商：移除「研究项目／私立科学家计划」（研究加成在全部科技已授予的 MOD 下无意义），保留并确保「高效扩展」等产量线；
  - 突击炮制造商：「改良型高爆穿甲弾」改为「改良型高爆弹药」（对装甲杀伤改为对人员）；
  - 长航程飞机制造商：确保点选「先进生产技术」与「长程战斗机」两个改进。
  - 附带修复：生成器 `maximum_legal_route` 评分改为排序后累加浮点数（原 set 迭代顺序依赖 PYTHONHASHSEED，跨进程/跨机可能产生互斥选边漂移）——本次产物以本机原版 1.19.2.0（d245 构建）为基准重建（444 机构、4877 特质；上一基准 7a45 构建产物 4944 特质，差异为等强度互斥换边与研究线移除）。
