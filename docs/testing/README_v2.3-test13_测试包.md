- 分类改为 `allowed = { always = yes }`，使所有国家在开局预先获得分类定义；当前界面仍由 `visible = { is_ai = no }` 控制。
- 所有16个决议继续在 `available` 保留 `is_ai = no`，并保留 `ai_will_do = { factor = 0 }`，AI不能执行。
- 初始化、统一改编、进化编制和五类特殊科研仍以各自国家完成标志控制每国一次。
- 通用初始化完成事件与PRC专属初始化完成事件已采用维护者确认的新文案，中英文同步。
- 继承test11的全国家通用MIO表：444家公司、4945项目标特质；不增加额外MIO资金或等级。
