> 状态：开发态测试包，未打正式标签、未上传 Steam 工坊。当前正式稳定基准仍为 v2.9。本包承载玩家 2026-08-24 反馈批（整理评估见 `docs/analysis/v2.9_QQ交流群反馈整理与评估_2026-08-24.md`）的全部静态修复与调整，另有三项「完全失效」反馈待实机确诊后随批修复；待统一实机回归＋玩家复测后定版。

## 本轮变更（继承 v2.9 正式版）

### 缺陷修复

- **年份科技归组（B1）**：分散的消防管道、柴油动力应急泵、阶梯射击、染色弹（`damage_control_2/3`、`fire_control_methods_2/3`）此前不在任何年份组，现随一级键一并归入「1936及以前」；重点防护装甲方案（`improved_heavy_armor_scheme`）由 1938 改归 1936（机主拍板，玩家两次点名）。
- **建筑槽位（B5）**：共享建设槽一次授予 25→**100**，超出引擎上限部分自动截断；兼容提高槽位上限的 MOD。

### 功能调整

- **电网（F1）**：一键建设电网统一为**大容量电网**（`industrial_infrastructure`），不再按产油州分支铺强化电网（原版两种电网同州互斥，州上限 1）。
- **规则归位（F2）**：「对未造成紧张度的国家正当化战争目标」从「制造战争借口」挪入「解锁特殊规则」；「制造战争借口」现在只制造吞并借口。
- **点数（F3）**：政治点、指挥点、三军经验每次点击全部 +99999（原指挥点 +100、经验 +999）。
- **好感（F4）**：改善全国家关系 +1000→**+5000**（永久自定义修正）。
- **进化库存转移（F5）**：「进化特殊科研陆军编制」不再附带发放直升机/装甲支援车/中型喷火坦克 III型库存；三类装备改由「获得巨量装备库存」（及补给）在进化完成后一并补充。

### 待实机确诊项（本批未改代码）

- **B2 顺从度「完全失效」**：源码静态未见缺陷；疑似测试场景为已拥有州（引擎本就没有抵抗语义）或 test6 改动回归——回归清单第 2 项确诊。
- **B3 国策特殊科技「完全失效」**：键均在 `research_all` 与 1936 组；疑似 DLC 门禁/隐藏键静默跳过或一键开局中断——回归清单第 3 项确诊（后半句「科研所非选项科技」经 P1 三表对账证伪，50 个非选项键全覆盖，见 `docs/analysis/v2.9_特殊科研三表对账_2026-08-24.md`）。
- **B4 一键填充顾问「完全失效」**：10 个角色键已核原版存在；`PRC_luo_shunchu`/`PRC_liu_yalou` 的 `allowed` 含 NCNS 门禁，疑似无该 DLC 时任命失败——回归清单第 4 项确诊。
