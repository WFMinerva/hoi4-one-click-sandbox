# 开局一键爽玩 v2.3-test4 测试包

> 状态：德国实测发现通用初始化没有自动完成MIO特质路线，已由 v2.3-test5 取代。当前正式基准仍为 v2.2。

## 本轮目标

- 保留已通过德国实机回归的 v2.3-test3 通用进化分支。
- 将PRC基础“主力步坦师”中的1个轻型自行火炮营改为中型自行火炮营，目标为15民兵＋3中型自行火炮。
- 将通用国家基础“主力步坦师”中的1个轻型自行火炮营同步改为中型自行火炮营，目标为15普通步兵＋3中型自行火炮。
- 不改变两套模板的支援连、PRC师名组和兵牌边界。
- 德国MIO特质与方针可参照维护者的 `test4.hoi4` 人工核对；MIO方针不属于MOD自动初始化承诺。

## MIO方针边界

原版1.19.2脚本文档提供检查MIO方针以及修改方针冷却和花费的接口，但没有为指定MIO挂载或选择方针的效果。因此本测试包不会猜测未文档化存档字段，也不会声称自动完成方针选择；方针继续由玩家手动选择。

## 安装边界

测试包只用于本机回归。安装目录继续使用 `OCS_one_click_sandbox_start_v2_0`；不得覆盖 Steam 工坊正式内容，不得创建正式标签或 Release。

## 验证依据

实机回归项目见同包 `v2.3-test4_实机回归清单.md`。工程检查会锁定PRC与通用基础“主力步坦师”的兵种数量和“不得含轻自火”约束，但不能替代游戏内验证。
