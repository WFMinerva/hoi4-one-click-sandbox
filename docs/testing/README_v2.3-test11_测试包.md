## 本轮修正

- 共享 MIO 效果改为全国家通用公司表，不包含国家 tag 分支。
- 原版正常定义中的 444 家目标公司均使用“当前国家拥有检查＋直接 `mio:` 作用域”；不存在的公司自动跳过。
- 共登记 4945 次 `complete_mio_trait`。德国沿用 test7 的319项；英国按 test8 补为177项；test9/test10 实际已点路线共1190项。
- test9/test10 中没有实际点出特质的23家公司按维护者口径排除，不处理国策前置、互斥路线另一侧或未实例化公司。
- 其余未采样公司由生成器选择最大合法特质集合，并按父节点拓扑排序；相同生成规则适用于所有玩家国家。
- PRC 原有4家专属 MIO 继续由增强层独立维护。
- 不使用 `add_mio_funds`，不额外使用 `add_mio_size`；MIO 方针仍由玩家手动选择。

测试包只用于本机回归，不覆盖 Steam 工坊内容，不创建正式标签或 Release。实机项目见同包 `v2.3-test11_实机回归清单.md`。
