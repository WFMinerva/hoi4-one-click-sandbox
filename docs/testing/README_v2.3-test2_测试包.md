# 开局一键爽玩 v2.3-test2 测试包

> 状态：已由维护者完成PRC实机回归，未发现问题；随后被含通用进化分支的 v2.3-test3 取代。当前正式基准仍为 v2.2。

## 本轮目标

- 以维护者手调存档 `test3.hoi4` 中的基础“装甲师”为目标，而不是沿用已证伪的10＋8记录。
- PRC与通用国家的基础“装甲师”均采用12个机械化营＋6个中型自行火炮营。
- 营网格固定为机械化 `x=0..2/y=0..3`、中型自行火炮 `x=3..4/y=0..2`。
- 团级支援固定为3个 `mot_fire_support`＋2个 `medium_tank_destroyer_support`。
- 普通支援连固定为炮兵、工兵、轻坦侦察、后勤和野战医院。
- 独立“装甲师·进化型”仍保持原有12＋6和进化型普通支援连，不因基础模板修改而混改。

## 安装边界

测试包只用于本机回归。安装目录继续使用 `OCS_one_click_sandbox_start_v2_0`；不得覆盖 Steam 工坊正式内容，不得创建正式标签或 Release。

## 验证依据

实机回归项目见同包 `v2.3-test2_实机回归清单.md`。自动回归逐项锁定两份基础模板的营类型、坐标、团级支援和普通支援连，并继续单独锁定“装甲师·进化型”。静态检查与构建结果不能替代游戏内验证。
