# 开局一键爽玩 v2.3-test12 测试包

> 状态：待维护者实机回归的测试包，不是正式稳定基准。当前正式基准仍为 v2.2。

## 本轮修正

- 初始化、统一改编、进化编制与五类特殊科研共8个一次性决议显式设置 `fire_only_once = no`。
- 每项功能仍以国家完成标志控制：同一国家完成后消失，切换到尚未完成的玩家国家后重新可见，因此可在同一局依次测试多个国家。
- 通用初始化事件、补库存、交通建设、24师和进化编制的共享说明改为按当前国家分支描述，不再向非PRC国家解释PRC顾问、中国型号或中国固定补给站。PRC专属事件与实际增强效果保持不变。
- 继承test11的全国家通用MIO表：444家公司、4945项目标特质；只处理当前国家实际拥有的机构。
- 不使用 `add_mio_funds`，不额外使用 `add_mio_size`；MIO方针仍由玩家手动选择。

## 测试边界

测试包只用于本机回归，不覆盖Steam工坊内容，不创建正式标签或Release。实机项目见同包 `v2.3-test12_实机回归清单.md`。
