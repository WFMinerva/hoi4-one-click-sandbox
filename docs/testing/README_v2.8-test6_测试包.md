# 开局一键爽玩 v2.8-test6 测试包

> 状态：开发态测试包，未打正式标签、未上传 Steam 工坊。当前正式稳定基准仍为 v2.7（Steam 物品 3767025052）。

## 本轮修复（继承 v2.7 正式基准与 v2.8-test5，变更记录 #7）

- **共享 MIO 路线表机构守卫**：`tools/analyze_mio_archetypes.py` 现在解析原版机构 `allowed` 块，`tools/generate_universal_mio_effect.py` 按其为每家机构生成前置守卫（DLC 门禁、国家归属，OR/AND/NOT 结构保真；含 `FROM` 的机构维持原守卫）。作用：玩家缺对应 DLC 时不再触发无效机构键错误、对应机构正确跳过；PRC 引用按红线 3 双覆盖（`tag = PRC` 与 `original_tag = PRC`）。表内 444 机构、4944 特质数据不变。
- **自检套件补共享 MIO 链用例**：新增 `mio_shared_chain`（固定用例 7→8，共 51 用例），实机回归时实际执行一次共享 MIO 路线链；配合 `tools/check_logs.py` 的 error.log 新签名报警，未来任何机构/特质键漂移（游戏热修、原版改名）都会在维护者回归轮被捕获。
- **版本差异说明**：MIO 路线表按最新游戏版本（1.19.2）原版数据生成；若游戏停在旧热修（如 1.19.1），个别机构/特质在该版本不存在，表现为该机构未点选、`error.log` 出现对应提示——属版本差异而非 MOD 缺陷，更新游戏后即完整。

## 测试边界

本测试包仅用于维护者实机回归与玩家 MIO 项复测；不覆盖 Steam 工坊内容，不创建正式标签或 Release。实机结论、SHA-256 与逐项清单见同包 `v2.8-test6_实机回归清单.md`。
