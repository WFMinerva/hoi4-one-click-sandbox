# 开局一键爽玩 v2.3-test5 测试包

> 状态：维护者以英国测试后确认大体正常，但独立MIO补齐决议多余，且额外MIO等级会留下特质点；已由 v2.3-test6 取代。当前正式基准仍为 v2.2。

## 本轮目标

- 保留v2.3-test4的基础“主力步坦师”中自火修正；不改动“改进型履带登陆车”。
- 从维护者的 `test4.hoi4` 提取25家德国MIO共255个已完成特质，作为首批共享公司目标路线。
- 按公司键而不是当前国家匹配。同一个德国公司出现在其他国家时，使用同一条特质路线；未拥有的公司自动跳过。
- 基础初始化自动配置当前已有公司；新增可重复“补齐共享军工机构特质”决议，处理初始化后通过国策或外国合作获得的公司。
- PRC原有4家专属MIO路线保持独立，不被德国公司路线替换。
- MIO方针继续由玩家手动选择。

## 风险边界

原版MIO定义允许部分德国公司被其他国家使用，但外国实例的公司专属特质附带效果仍需要实机回归。测试前不得把“机构键能够匹配”误记为所有外国效果均已验证。

## 安装边界

测试包只用于本机回归。安装目录继续使用 `OCS_one_click_sandbox_start_v2_0`；不得覆盖 Steam 工坊正式内容，不得创建正式标签或 Release。

## 验证依据

实机回归项目见同包 `v2.3-test5_实机回归清单.md`。自动回归锁定25家公司、255个特质、公司键匹配、幂等终点、初始化调用和可重复决议，但不能替代游戏内MIO界面验证。
