## 本轮新增（继承 v2.6-test1 + v2.5 正式基准）

- 特殊科研"逐项选择版"26 组扩展：在 v2.6-test1 空军/海军各 3 组（事件 14/18 链）之上，新增 26 组互斥原型奖励事件（事件 22–47）。
  - 空军 4 组：地震炸弹、直升机、洲际轰炸机、空天母舰（菜单事件 50）。
  - 陆军 3 组：要塞网络·混凝土加固（一）、混凝土加固（二）、通信系统改造（菜单事件 48）。
  - 海军 17 组：护航航母 A/B、冰航母、袖珍潜艇、现代战列舰 A/B、现代航母 A/B、核导弹潜艇、核潜艇、导弹潜艇、潜水母舰、超级战列舰 A/B、支援船·支援方案、支援船·维修方案、补给船（菜单事件 51）。
  - 核能 2 组：核同位素分离（气体扩散/离心分离）、核反应堆测试完成（保密处理/向公众公开）（菜单事件 49）。
- **修复生成器按 project 去重缺陷**：每个 reward 组独立生成事件 id 与独立 country flag（flag 含 reward 后缀），同 project 的多组（如要塞网络 3 组、海军 `_a/_b` 组、核反应堆 2 组）全部可逐项选定，不再互相遮蔽。
- **交互接线**：组事件选项末自动返回本专精菜单（48/49/50/51）；新增陆/核"选择原型奖励"决议（入口 48/49）；空军/海军主菜单 14/18 末尾新增".e"续入口跳转 50/51；菜单 z 选项在全部组选定后设置该专精完成 flag，决议随之隐藏。
- 新增 `tools/generate_special_project_choice_events.py`（生成组事件+映射 JSON）、`tools/finish_choice_events.py`（幂等生成菜单与双语本地化）、`docs/analysis/v2.6_特殊科研组事件映射.json`（26 组 id/flag/菜单权威映射）。
- 本地化补齐 26 组事件 title/desc/option 与 48–51 菜单，中英双语同步；修复 test1 中 46/47 标题错位（同位素分离/测试完成奖励各归其位）。
- 效果数值全部取自原版 `unique_prototype_rewards`（含 DLC 分支），未发明新数值。
