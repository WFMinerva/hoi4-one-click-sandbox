# 开局一键爽玩 v2.6-test1 测试包

> 状态：开发态测试包，未打正式标签、未上传 Steam 工坊。当前正式稳定基准仍为 v2.5（Steam 物品 3767025052）。

## 本轮新增（继承 v2.5 正式基准）

- 特殊科研"逐项选择版"两套系统：新增空军、海军两个"选择原型奖励"决议，在"一键完成"之后以事件链形式逐项发放原版互斥原型奖励 buff。
  - 空军 3 组：喷气引擎（战斗机/折中/轰炸机）、轴流式喷气引擎（战斗机/折中/轰炸机）、超音速战斗机（减价/均衡/高性能）。
  - 海军 3 组：巡洋潜艇（航程/鱼雷）、舰队潜艇（攻击与隐蔽/可靠与防护）、雷击巡洋舰（鱼雷/副炮）。
  - 每组每国只可选定一次；全部选定后决议隐藏。效果数值全部取自原版 `unique_prototype_rewards`（含 DLC 分支），未发明新数值。
- 新增 `tools/analyze_special_project_choices.py`：解析原版特殊项目文件，导出全部互斥 buff 清单（`docs/analysis/v2.6_特殊科研互斥选项清单.md`/`.json`），为后续扩展其余专精提供权威依据。

## 测试边界

本测试包仅用于维护者实机回归验证上述新增项；不覆盖 Steam 工坊内容，不创建正式标签或 Release。实机结论与逐项清单见同包 `v2.6-test1_实机回归清单.md`。
