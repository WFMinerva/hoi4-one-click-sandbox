# 开局一键爽玩 v2.2-test1 测试包

> 状态：历史测试包。维护者已完成中文环境实机回归，结果已正式化为 v2.2；本文件保留测试过程与验证依据。

## 本轮目标

- PRC 在喷火坦克、军用工程车、直升机、洲际轰炸机、空天母舰、轴流式喷气引擎项目及精确相关科技完成后，可执行一次“进化特殊科研陆军编制”。
- 新建“司令部”“装甲师·进化型”“海军陆战队装甲师·进化型”“主力步坦师·进化型”，不覆盖旧模板，不自动改编现役师。仅司令部与主力步坦师按目标存档显式指定兵牌；另两者没有手调兵牌目标，保持引擎默认。
- 新建最终“中型喷火坦克 III型”，基础初始化不再创建或发放“43式喷火预备”。
- 新建全5升级“改进型履带登陆车”，不分配MIO，并退役旧设计。
- 新建四个同名“装甲支援车”，分别保留指挥、突击工程、架桥工程和装甲维修角色，四项升级均为 5。
- 新建空天母舰、洲际轰炸机、喷气式战略轰炸机I型、喷气式战术轰炸机II型四种全5设计并退役旧版；人民航空公司军工机构存在时自动选用。
- “组建24个满编主力纯步师”改为可重复决议，每次完成后等待 1 天。

## 已接受限制

- 基础初始化生成的“装甲师”本测试版仍为8机械化＋10中型自行火炮。维护者接受当前版本保留该结构，后续版本调整为10机械化＋8中型自行火炮。
- “装甲师·进化型”是独立的12机械化＋6中型自行火炮模板，不属于上述后续调整。

## 安装边界

测试包只用于本机回归。安装目录继续使用 `OCS_one_click_sandbox_start_v2_0`，不得改变正式工坊物品或稳定标签。

## 验证依据

实机回归项目见同包 `v2.2-test1_实机回归清单.md`。静态检查与构建结果只证明文件、结构和产物一致性，不能替代游戏内验证。

原版 UI 虽支持玩家手动退役编制，但当前没有已确认可安全调用的模板退役 effect 或存档字段。本测试包不会自动退役旧模板，更不会使用会删除现役师的 `delete_unit_template_and_units`。
