# 开局一键爽玩 / One-Click Sandbox Start v2.3

状态：维护者已于2026-07-31完成关键实机回归并认定为稳定版；已上传 Steam 工坊既有物品 `3767025052`（Manifest `7223939852636260892`）。Git标签与无附件Release在发布分支合并后创建。

适用环境：Hearts of Iron IV 1.19.*，全 DLC，单人游戏。AI 不会执行本 MOD 决议。特殊科研项目及二阶段编制需相关 DLC。

## 定位

v2.3 将“通用核心 + PRC增强层”进一步扩展为真正面向所有玩家国家的一键初始化：共享MIO路线按当前国家实际拥有的公司处理，一次性功能按国家分别记录，同局切换控制国家后仍可继续使用。

## v2.3 新增与修正

- 生成器维护444家原版军工机构、4945项目标特质；存在的公司立即完成合法路线，不存在的公司安全跳过。
- 不额外增加MIO资金或等级，不留下人为制造的剩余特质点；MIO方针仍由玩家手动选择。
- 初始化、统一改编、进化编制及五类特殊科研均为每个玩家国家各执行一次，完成后对该国家消失。
- 分类在开局为所有国家实例化，但仅对非AI玩家显示和开放；维护者实机确认同局切换国家后分类正常出现。
- 基础“装甲师”改为12机械化＋6中型自行火炮；“主力步坦师”与其进化型的轻型自行火炮纠正为中型自行火炮。
- 特殊科研后二阶段进化编制开放给所有非AI玩家国家；通用国家使用普通步兵及中性装备名称，PRC保留独立增强层。
- 决议前置条件不足时保持可见并灰显，提示需要先完成的决议。
- 更新维护者定稿的通用与PRC初始化事件文案。

## 已接受边界

- MIO方针无法通过当前原版已公开脚本效果为指定机构自动选择，继续由玩家手动处理。
- 不修改原版国策、国家历史文件或事件链，不创建舰船设计或舰队。
- 建设仅处理当前国家拥有且控制的州。

## 安装

将 `OCS_one_click_sandbox_start_v2_0` 文件夹和 `OCS_one_click_sandbox_start_v2_0.mod` 放入 Hearts of Iron IV 的 mod 目录，然后在启动器中启用。

本正式包仅由 `tools/build_release.py` 从仓库构建，包内逐文件校验见 `MANIFEST_SHA256.csv`。
