# 开局一键爽玩 / One-Click Sandbox Start v2.9

状态：维护者于 2026-08-23 明确要求发布 Steam 工坊。适用 Hearts of Iron IV 1.19.*、全 DLC、单人游戏；AI 不会执行本 MOD 决议。

## 定位

v2.9 在 v2.8 稳定基准上扩展开局生产工具：把研究、政治、外交、装备与建设操作拆成可理解、可重复点验的独立决议，并把 CWTools 语义检查接入本地门禁。

## 主要变化

- 按年份研究与一键全科技修正；剔除隐藏史前科技。
- 稳定度、战争支持、自治度、顺从度、国际关系、意识形态、法案、战争借口与特殊规则控制。
- 预设设计与库存分离，补齐飞机和舰船变体；库存需先创建设计。
- 全国军工厂、电网、要塞群、大型设施独立建设；建设加速 +5000%。
- 《Götterdämmerung》下大型设施优先民用核反应堆，特殊科研不再补建冲突的普通核反应堆。
- 潜艇 MIO 路线与改善关系效果补全。
- CWTools 固定供应链本地语义检查；配合仓库验证器与 48 项单元测试。

## 验证边界

v2.9-test1 具有完整判定归档。2026-08-23 对最终核能修复完成实机点验：暂停状态执行大型设施即可生效；载入 `nuclear_with_commercial_pre` 后完成核能特殊科研，首都最终为民用核反应堆 1、普通核反应堆 0；最终 `error.log`、`text.log` 均为 0 字节。v2.9-test6 统一清单的其余项目没有逐项补录结果，因此本基准不把它们表述为已有独立实机证据。

本轮小修按维护者明确指示免除 Kimi K3 复检；这是一条例外，不改变后续维护流程。

## 安装

将 `OCS_one_click_sandbox_start_v2_0` 文件夹和同名 `.mod` 文件放入 Hearts of Iron IV 的 mod 目录，在启动器启用。
