# 开局一键爽玩 / One-Click Sandbox Start v2.0

状态：用户已实机验证并明确认定为稳定版。

适用环境：Hearts of Iron IV 1.19.*，全DLC，单人游戏。AI不会执行本MOD决议。

## 定位

v2.0将原PRC专用方案改造为全国家通用核心。所有非AI玩家国家均可使用科技、学说、装备设计、师级编制、库存、全国建设和24个满编主力纯步师等功能；PRC额外保留原有顾问、军事高层、四家军工机构特质、中国型号、23座固定补给站和双电网。

## 安装

将 `OCS_one_click_sandbox_start_v2_0` 文件夹和 `OCS_one_click_sandbox_start_v2_0.mod` 放入 Hearts of Iron IV 的 mod 目录，然后在启动器中启用。

## 关键规则

- 建设只处理当前国家拥有且控制的州，不处理临时占领区。
- 其他国家完全不建设电网，也不获得中国固定补给站。
- PRC保留双电网和23座固定补给站。
- 初始化不会自动改动现役师；“统一改编现有陆军”是独立且不可逆的选择。
- PRC通用模板保留民兵结构；其他国家相应模板使用普通步兵。
- “组建24个满编主力纯步师”一次性生成24个100%人力、装备和训练度的师。

本正式包仅清理v2.0c2测试标识并更新版本信息，未改变已验证的游戏逻辑。
