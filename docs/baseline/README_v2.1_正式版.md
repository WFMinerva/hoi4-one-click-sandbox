# 开局一键爽玩 / One-Click Sandbox Start v2.1

状态：维护者已实机验证通过并认定为稳定版，已上传 Steam 工坊（物品 ID 3767025052，2026-07）。

适用环境：Hearts of Iron IV 1.19.*，全 DLC，单人游戏。AI 不会执行本 MOD 决议。特殊科研项目决议需《Gotterdammerung》DLC。

## 定位

v2.1 在 v2.0（全国家通用核心 + PRC 增强层）之上新增特殊科研项目一键完成功能，其余游戏逻辑与 v2.0 完全一致。所有非 AI 玩家国家可使用科技、学说、装备设计、师级编制、库存、全国建设、24 个满编主力纯步师和五类特殊科研项目决议；PRC 额外保留顾问、军事高层、四家军工机构特质、中国型号、23 座固定补给站和双电网。

## v2.1 新增

- 按空军（含雷达，9 项）、陆军（9 项）、海军（19 项）、核能（6 项）、火箭（6 项）五类专精一键完成全部 49 个特殊科研项目，完成奖励与正常研究完全一致。
- 直接授予 57 项衍生科技与原型迭代互斥选择科技（含离心法同位素分离、海军补给与维修方案）。
- 核能决议在首都补建 1 座核反应堆，替代正常研究时设施州自动获得的反应堆。
- 决议可重复执行：跨专精前置被跳过时，完成其他专精后再次点击即可补齐；全部完成后决议自动消失。

## 安装

将 `OCS_one_click_sandbox_start_v2_0` 文件夹和 `OCS_one_click_sandbox_start_v2_0.mod` 放入 Hearts of Iron IV 的 mod 目录，然后在启动器中启用。

## 关键规则

- 建设只处理当前国家拥有且控制的州，不处理临时占领区。
- 其他国家完全不建设电网，也不获得中国固定补给站。
- 初始化不会自动改动现役师；"统一改编现有陆军"是独立且不可逆的选择。
- PRC 通用模板保留民兵结构；其他国家相应模板使用普通步兵。
- "组建 24 个满编主力纯步师"一次性生成 24 个 100% 人力、装备和训练度的师。

本正式包仅由 `tools/build_release.py` 从仓库构建，包内逐文件校验见 `MANIFEST_SHA256.csv`。
