# 开局一键爽玩 / One-Click Sandbox Start v2.4

状态：继承 v2.3 正式基准的修复集，维护者已于2026-08-01完成 v2.4-test1 实机回归并认定为稳定版；已推送 Git 标签 `v2.4`，并于 2026-08-01 上传 Steam 工坊既有物品 `3767025052`（Manifest `385131838239799795`）。

适用环境：Hearts of Iron IV 1.19.*，全 DLC，单人游戏。AI 不会执行本 MOD 决议。特殊科研项目及二阶段编制需相关 DLC。

## 定位

v2.4 在 v2.3 全国家通用 MIO、分类跨国家切换与每国一次性功能基础上，完成一批玩家反馈修复：雷达科技归位空军特殊科研、进化装备设计与库存同步、船坞/民用工厂可重复点至上限、全地图碉堡收敛、点数/经验剥离为独立决议，并修复本地部署加载结构。

## v2.4 新增与修正

- 一级/二级雷达科技从初始化移除，并入“完成空军特殊科研项目”奖励；完成后雷达科技 1–5 级全部点亮（含高三级雷达）。
- 直升机、装甲支援车（4 款变体）和中型喷火坦克 III型 移入进化效果末尾；执行“进化特殊科研陆军编制”后设计与库存同时出现，初始化与补给不再直接授予。
- 修复“沿海船坞建设”“民用工厂建设”只能点一次：每次点击前重置 5 个步骤标志，完成判断仅由 `dockyard > 19` / `industrial_complex > 19` 决定，可重复点至上限。
- “构筑全国防御工事”不再在陆地省份修筑五级碉堡；防空（5 级）与海岸要塞（10 级）保留。
- 政治点/指挥点/三军经验从初始化与补给效果剥离，新建独立可重复决议 `PRC_OCS_add_points`（英/简中本地化同步）。
- 修复 `Expand-Archive` 双重嵌套目录与 `.mod` 文件 `path` 层级不匹配导致的加载失败。

## 已接受边界

- MIO 方针无法通过当前原版已公开脚本效果为指定机构自动选择，继续由玩家手动处理。
- 不修改原版国策、国家历史文件或事件链，不创建舰船设计或舰队。
- 建设仅处理当前国家拥有且控制的州。
- 潜艇 MIO 全局隐蔽线、间谍机构研发及特殊研发科技强度优化不在本版范围（见交接文档待办）。

## 安装

将 `OCS_one_click_sandbox_start_v2_0` 文件夹和 `OCS_one_click_sandbox_start_v2_0.mod` 放入 Hearts of Iron IV 的 mod 目录，然后在启动器中启用。

本正式包仅由 `tools/build_release.py` 从仓库构建，包内逐文件校验见 `MANIFEST_SHA256.csv`。
