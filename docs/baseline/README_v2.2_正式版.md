# 开局一键爽玩 / One-Click Sandbox Start v2.2

状态：维护者已在中文环境完成实机回归并认定为稳定版；2026-07-30 已上传 Steam 工坊既有物品 `3767025052`（Manifest `6814589756424432401`）。

适用环境：Hearts of Iron IV 1.19.*，全 DLC，单人游戏。AI 不会执行本 MOD 决议。特殊科研项目及二阶段编制需相关 DLC。

## 定位

v2.2 在 v2.1 的五类特殊科研项目决议之上，新增 PRC 特殊科研后二阶段编制与最终装备设计，并将一键组建24个满编主力纯步师改为可重复执行。

## v2.2 新增

- PRC满足6个指定特殊科研项目及9项相关科技后，可一次性创建“司令部”“装甲师·进化型”“海军陆战队装甲师·进化型”和“主力步坦师·进化型”。
- 创建最终“中型喷火坦克 III型”、全5升级“改进型履带登陆车”、4个角色不同的全5“装甲支援车”，以及4种全5特殊轰炸机。
- 人民航空公司军工机构存在时，4种特殊轰炸机自动使用该机构；PRC后继身份缺少机构时仍可创建无MIO设计。
- 一键24师改为可重复执行，每次完成后冷却1天。
- 保留旧模板和现役单位，不自动删除、退役或改编。

## 已接受限制

- 基础初始化“装甲师”本版仍为8机械化＋10中型自行火炮；后续版本调整为10＋8。
- 独立的“装甲师·进化型”为12机械化＋6中型自行火炮，不属于上述后续调整。
- Steam工坊简介本次只同步中英文“当前稳定版本”为v2.2，其余正文不改，也不提交工坊更新日志。

## 安装

将 `OCS_one_click_sandbox_start_v2_0` 文件夹和 `OCS_one_click_sandbox_start_v2_0.mod` 放入 Hearts of Iron IV 的 mod 目录，然后在启动器中启用。

本正式包仅由 `tools/build_release.py` 从仓库构建，包内逐文件校验见 `MANIFEST_SHA256.csv`。
